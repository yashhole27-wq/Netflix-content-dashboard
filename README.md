# 🎬 Netflix Content Analysis Dashboard | Power BI

An interactive **Power BI dashboard** built to analyze Netflix's content library and uncover insights related to titles, content types, genres, countries, audience groups, and content addition trends.

The project focuses on transforming Netflix content data into an interactive business intelligence dashboard that makes it easier to understand the composition and evolution of the Netflix catalog.

---

## 📊 Dashboard Overview

The dashboard provides a high-level view of Netflix's content library through interactive KPIs, charts, tables, and slicers.

### Key KPIs

* 🎬 **Total Titles**
* 🎥 **Movie Share**
* ⏱️ **Average Movie Length**
* 📺 **Average Seasons per Show**
* 🌎 **Number of Countries**

### Key Analysis

* Content added over the years
* Movies vs TV Shows
* Top genres
* Top countries by number of titles
* Audience group distribution
* Year and month-wise content additions
* Interactive filtering by content type and country

---

## 🔍 Key Insights

Some of the insights identified through the dashboard include:

* **Movies account for approximately 69.6%** of the Netflix content library.
* **International Movies** are the top genre, with **2,752 titles**.
* The **United States is involved in approximately 42%** of all titles.
* **2019** was the busiest year for content additions, with nearly **2,000 titles**.
* The dashboard also provides a breakdown of content based on audience groups, countries, genres, and content type.

> These insights are based on the data available in the dashboard and may change depending on the filters applied.

## 📈 Dashboard Components

### 1. KPI Overview

The dashboard begins with key performance indicators that summarize the Netflix catalog:

| KPI                  | Description                                     |
| -------------------- | ----------------------------------------------- |
| Total Titles         | Total number of titles available in the dataset |
| Movie Share          | Percentage of titles classified as movies       |
| Avg Movie Length     | Average movie duration in minutes               |
| Avg Seasons per Show | Average number of seasons for TV shows          |
| Countries            | Number of countries represented in the dataset  |

### 2. Content Addition Trends

A time-series analysis shows how Netflix content additions changed over the years and provides a comparison between **Movies and TV Shows**.

### 3. Genre Analysis

The dashboard identifies the most represented genres and highlights the genres with the largest number of titles.

### 4. Country Analysis

A country-level analysis shows which countries are most represented in the Netflix catalog.

### 5. Audience Analysis

Content is categorized into different audience groups to understand the distribution of Netflix titles across audience classifications.

### 6. Year & Month Analysis

A detailed year/month breakdown provides additional visibility into when content was added to the Netflix catalog.
